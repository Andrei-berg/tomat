# Tomato Sales (Учёт продаж помидоров)

## What This Is

Web-приложение для ежедневного учёта продаж помидоров с фуры. Заменяет бумажную тетрадь Рустама: фиксация продаж, отслеживание долгов, отчёт за период. Два пользователя (продавец + владелец) работают с одного общего пароля.

## Core Value

Продавец должен быть в состоянии за 30 секунд оформить продажу прямо с телефона — быстрее, чем записать в тетрадь.

### Out of Scope

- Мульти-точки / мульти-фуры — только одна точка (Рустам), расширение потом
- Индивидуальные аккаунты пользователей — общий пароль достаточен
- Офлайн-режим — всегда онлайн
- Управление товарами — список фиксирован, меняется через БД
- Push-уведомления — не нужны на старте

## Context

Бизнес: база помидоров в Махачкале, оттуда фуры едут в разные города. В каждом городе может быть несколько точек. Сейчас делаем для Рустама (одна точка). Если собственник оценит — продукт может вырасти в мульти-точечный. Дизайн БД должен не мешать этому расширению, но не должен усложнять v1.

Товары (фиксированный список, sort_order 1–6): Пятерка, Шестерка, Семерка, Восьмерка, НС, Хара-Хура.

Текущий инструмент: бумажная тетрадь. Цена ошибки замены — высокая, интерфейс должен быть очевидным с первого использования.

## Constraints

- **Tech Stack**: Next.js 15 (App Router), TypeScript, Supabase (PostgreSQL), Tailwind CSS — уже выбрано
- **UI Language**: Код на английском, весь UI на русском
- **Platform**: Web, mobile-first (Рустам работает с телефона)
- **Connectivity**: Always online, офлайн не нужен
- **Auth**: Один общий пароль — не Supabase Auth, простая проверка на сервере
