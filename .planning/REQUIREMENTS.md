# Requirements: Tomato Sales

**Defined:** 2026-04-28
**Core Value:** Продавец оформляет продажу за ≤30 секунд с телефона — быстрее, чем тетрадь

## v1 Requirements

### Auth

- [ ] **AUTH-01**: Неаутентифицированный пользователь перенаправляется на /login с любой страницы
- [ ] **AUTH-02**: Пользователь входит с одним общим паролем
- [ ] **AUTH-03**: Сессия сохраняется после обновления браузера
- [ ] **AUTH-04**: Пользователь может выйти из системы

### Prices

- [ ] **PRICE-01**: Пользователь может установить цену за кг для каждого из 6 товаров на текущий день
- [ ] **PRICE-02**: Пользователь может скопировать цены предыдущего дня одной кнопкой

### Clients

- [ ] **CLIENT-01**: Пользователь может создать заказ без указания клиента (анонимный)
- [ ] **CLIENT-02**: Пользователь может выбрать существующего клиента при создании заказа
- [ ] **CLIENT-03**: Пользователь может добавить нового клиента прямо при оформлении заказа

### Orders

- [ ] **ORDER-01**: Пользователь может добавить несколько позиций в заказ (товар, ящики, вес; цена подставляется автоматически)
- [ ] **ORDER-02**: Пользователь может применить скидку в процентах к заказу
- [ ] **ORDER-03**: Пользователь может вручную переопределить итоговую сумму заказа
- [ ] **ORDER-04**: Пользователь выбирает тип оплаты: Наличные / Карта / Долг
- [ ] **ORDER-05**: Пользователь не может сохранить пустой заказ (кнопка неактивна)
- [ ] **ORDER-06**: Пользователь не может сохранить долговой заказ без имени клиента
- [ ] **ORDER-07**: Пользователь видит предупреждение при скидке > 50%
- [ ] **ORDER-08**: Пользователь видит запрос подтверждения, когда manual_total < 80% от calculated_total
- [ ] **ORDER-09**: Пользователь перенаправляется на /prices при создании первого заказа дня без установленных цен
- [ ] **ORDER-10**: Товар без цены на сегодня недоступен для добавления в заказ (с сообщением)
- [ ] **ORDER-11**: Пользователь может просмотреть список всех заказов

### Debts

- [ ] **DEBT-01**: Пользователь видит список всех клиентов с остатком долга > 0
- [ ] **DEBT-02**: Пользователь может зафиксировать полное или частичное погашение долга
- [ ] **DEBT-03**: Пользователь может просмотреть историю погашений по каждому долгу

### Report

- [ ] **REPORT-01**: Пользователь может посмотреть выручку за период с разбивкой по типам оплаты (наличные / карта / долги не получено)
- [ ] **REPORT-02**: Пользователь может посмотреть таблицу ящиков, кг и сумм по каждому товару за период
- [ ] **REPORT-03**: Пользователь может экспортировать отчёт в Excel
- [ ] **REPORT-04**: Пользователь может экспортировать отчёт в PDF

## v2 Requirements

### Multi-location

- **MULTI-01**: Поддержка нескольких точек продаж / фур
- **MULTI-02**: Отчёт по нескольким точкам в агрегированном виде

### Orders

- **ORDER-V2-01**: Аннулирование / отмена сохранённого заказа
- **ORDER-V2-02**: Редактирование сохранённого заказа

### Clients

- **CLIENT-V2-01**: Телефон и заметки клиента видны в экране долгов
- **CLIENT-V2-02**: Поиск клиента по телефону

## Out of Scope

| Feature | Reason |
|---------|--------|
| Offline mode | Всегда онлайн; добавляет значительную сложность без ценности |
| Индивидуальные аккаунты | Shared-пароль достаточен для 2 пользователей |
| Учёт остатков / инвентаризация | Другой домен — только продажи, не склад |
| Push-уведомления | Нет сценария с критической срочностью |
| Real-time sync | Нет параллельных пользователей на разных устройствах |
| Управление товарами (CRUD) | Список фиксирован — меняется только через БД |
