**getOrdersByDate(date: string)** — возвращает все заказы за дату (формат YYYY-MM-DD), отсортированные по created_at DESC. Запрос: `.gte('created_at', \`${date}T00:00:00+00:00\`).lte('created_at', \`${date}T23:59:59+00:00\`)`. Возвращает `OrderRow[]`.

**getOrderById(id: string)** — возвращает одну строку orders или null. Запрос: `.select('*').eq('id', id).single()`.

**getOrderWithItems(id: string)** — возвращает заказ с вложенными order_items и именем продукта. Запрос через join:
```
.select('*, order_items(*, products(name))')
```
Результат трансформировать: каждый item получает поле `product_name` из вложенного `products.name`. Возвращает `OrderWithItems | null`.
