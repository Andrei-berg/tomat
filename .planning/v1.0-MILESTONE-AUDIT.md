### Phase 1: Foundation
- **No logout button** (escalated to gap — AUTH-04 blocker)
- **No navigation between sections** — /prices and /orders have no links to each other; user must know URLs; root / redirects to /orders

### Phase 3: Orders
- **`getOrderById` dead export** in `src/lib/dal.ts` — exported but never imported; `getOrderWithItems` is used correctly for the detail page
- **ORDER-06 client-side only guard** — `createOrder` Server Action doesn't validate that debt orders must have a client; acceptable for single-user internal tool with no adversarial context
- **ORDER-09 return path** — `/prices` page has no CTA to return to `/orders/new` after saving prices; user must manually type URL

- `logout()` Server Action: ✓ implemented in `src/app/actions/auth.ts`

- Return path from /prices to /orders/new after saving prices
- `getOrderById` dead export in dal.ts
